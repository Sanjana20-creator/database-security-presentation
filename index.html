02 / SECURITY METHODS

How Do We Secure a Database?

Four important methods help protect a database from security threats.

01
👤

Authentication

It checks who the user is, for example, using a username, password, or OTP.

→
02
🔑

Authorization

It decides what a user is allowed to do. For example, an employee may view customer data but not delete it.

→
03
🔐

Encryption

It converts important data into a form that cannot be easily understood by unauthorized people.

→
04
📋

Auditing

It keeps a record of activities, such as who accessed the database or who changed the data.

✓ So these methods help us make sure that only the right people can access and use the database.

04 / SECURITY ISSUES
CHALLENGES

Major Security Challenges

!
⚠

SQL Injection

Attacker manipulates SQL queries to access data.

👤

Insider Threats

Authorized users misuse their privileges.

📤

Data Leakage

Sensitive information reaches unauthorized people.

⚖

Privacy and Compliance

Personal data must be protected by regulation.

⚙

Performance vs Security

Strong security can increase system overhead.

SQL INJECTION EXAMPLE 
SELECT * FROM Users
WHERE username = 'admin'
AND password = '' OR '1'='1';

Why does it work?

Unsafe code joins user input straight into the query. The OR '1'='1' part is always true, so the attacker can bypass the password check.
